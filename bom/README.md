# Bill of materials

`bom.xlsx` is the bill of materials and its single source of truth. Copy it to track your own
build. It has these sheets:

- **Summary**: totals per group, each split into owned, ordered and still to buy. All are
  formulas, so they follow your edits.
- **One sheet per group** (Servos, Compute & sensors, Power, Structure & materials). Each item
  has one line: an id, the item, the servo model where it is one, a **Status** dropdown (owned or
  ordered; empty means to buy), the quantity the robot uses, spares, unit price, a line total
  (formula, quantity plus spares), where the price came from, a source link and notes. Every
  status ships empty: mark what you own or have ordered in your copy. Owned lines keep their
  price, so the total stays the full cost to replicate.
- **Sourcing**: where each priced item was seen, with links, prices, the date checked and
  whether the price was confirmed on the seller's page.
- **Made parts (CAD)**: generated by `python -m cad.export` from the CAD (every part is printed;
  STLs go to `outputs/stl/`). CI checks that it is current. Its Status and Build notes columns
  are yours, and the export keeps them.

## Editing

`tools/bom/book.py` (Marvin Bot's tool, without its Lite column) keeps the workbook consistent.
Either edit the workbook by hand and then tidy it:

```bash
python tools/bom/book.py            # re-sort, re-format, rebuild formulas, dropdowns and Summary
```

Or edit it from the command line, which tidies it as well:

```bash
python tools/bom/book.py set sts3250 unit_usd=45 "price_basis=dealer 2026-12-01"
python tools/bom/book.py add usb-hub group=compute "item=USB 3 hub" qty=1 unit_usd=15
python tools/bom/book.py source imu "vendor=Some dealer" url=https://example.com unit_usd=29.50
python tools/bom/book.py set camera status=ordered
python tools/bom/book.py remove usb-hub
```

`python tools/bom/book.py --check` (CI) fails if a line is invalid or the workbook isn't tidy.
`python tools/bom/summary.py` prints the totals, and `tools/check_description.py` checks that
the servo lines list as many of each model as `description/robot.yaml` uses.

## Cost

At listed prices of 2026-11-10 the robot comes to about **$1,619** (`tools/bom/summary.py`):
servos $901, compute and sensors $324 (the Jetson Orin Nano Super developer kit is $249 of it),
power $243, structure and materials $150. Both servo models are priced at WowRobo's shop, which
sells them for SO-101 arms: STS3215-C018s at $13.99 in tens and $14.99 in fives, STS3250-C002s (the C001 without its
bracket, which the printed frame does not use) at $43. Elsewhere STS3250s cost about $46 from a
supplier listing and $74-97 at retail (a total of about $2,250). The order has one spare
STS3250 (also the bench unit) and six extra STS3215s: one spare, the rest kept for wrists
(up to two joints an arm, not designed yet). Not included: a desktop RTX GPU for
training, the 3D printer, shipping, import duties, tariffs and taxes.
